# HomeServe

A home repair service booking platform that connects customers with service providers for convenient and reliable home maintenance and repairs.

## Technologies

- Android Native
- Flutter
- Backend API

## Repositories

| Component | Description |
|---|---|
| Android | Native Android application |
| Flutter | Flutter application |
| Backend | Server-side logic and APIs |

## Project Overview

HomeServe aims to simplify the process of finding, booking, and managing home repair and maintenance services.
